# YVGSPCAM — GPS Map Camera

Android GPS Map Camera application (Susamp Infotech style) for geotagging photos with live satellite/road map thumbnails, coordinates (Decimal & DMS), street address, Plus Code, date/time (GMT), weather, wind, humidity, compass heading, altitude, magnetic field, custom stamp templates (**Classic** & **Advance**), offline map tile caching, and batch ZIP/KML/CSV cloud export.
