# YVGSPCAM — GPS Map Camera

Android GPS Map Camera application (Susamp Infotech style) for geotagging photos with live satellite/road map thumbnails, coordinates (Decimal & DMS), street address, Plus Code, date/time (GMT), weather, wind, humidity, compass heading, altitude, magnetic field, custom stamp templates (**Classic** & **Advance**), offline map tile caching, and batch ZIP/KML/CSV cloud export.

---

## 📥 Download Android APK

Once this repository is pushed to GitHub, **GitHub Actions** automatically builds the APK and publishes it in three places:

1. **Direct Repository File**: Look in the **[`releases/YVGSPCAM-debug.apk`](releases/YVGSPCAM-debug.apk)** folder after the GitHub Action finishes (~2 minutes after pushing).
2. **GitHub Releases**: Click **Releases** (`v1.0-latest`) on the right sidebar of this GitHub repository to download `YVGSPCAM-debug.apk`.
3. **GitHub Actions Artifact**: Open the **Actions** tab → click the latest **Build & Publish YVGSPCAM APK** run → download **`YVGSPCAM-debug-apk`** under *Artifacts*.

*(You can also download the APK directly inside Google AI Studio via the top-right **Settings (⚙️) → Generate APK** menu.)*
