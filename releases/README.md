# YVGSPCAM Android APK Release

Download **`YVGSPCAM.apk`** from this `releases/` directory to install and test **YVGSPCAM (GPS Map Camera)** on your Android device.

## Installation Instructions
1. Download `YVGSPCAM.apk` to your Android phone.
2. Tap the file to open the Android package installer.
3. If prompted, allow **"Install unknown apps"** and tap **"Install anyway"** on the Play Protect test-build prompt.
4. Open **YVGSPCAM** and grant **Camera** and **Location (GPS)** permissions.
